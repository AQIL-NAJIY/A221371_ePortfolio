Laboratory Work

Practical hands-on lab exercises and video demonstrations

3 Practical Labs
Lab 01

Android Security Baseline

Exploration of Android application sandboxing, permissions configuration, and local SQLite data storage encryption.

Reflection:

Completing this lab provided critical insights into mobile application permission models and key storage techniques. We learned how improper permission settings expose sensitive app data to unauthorized applications. This foundation is essential for hardening modern enterprise mobile solutions.

Lab 02

Network Layer Security

Implementing SSL/TLS certificate pinning and secure REST API calls using Retrofit and OkHttp interceptors.

Reflection:

This exercise highlighted how vulnerable mobile traffic is to Man-in-the-Middle (MITM) attacks if SSL certificates are not pinned correctly. By inspecting raw network packets, we learned how to sanitize transit data effectively. Overall, it reinforced best practices for secure web-service communication.

Lab 03

Cloud Integration & Auth

Configuring Firebase Firestore security rules and OAuth authentication tokens for seamless multi-factor auth.

Reflection:

Setting up Firebase rules allowed us to understand fine-grained access control in serverless backend architectures. We experienced firsthand how default permissive rules lead to backend database leaks. Writing strict rules ensured data integrity across all user roles.
